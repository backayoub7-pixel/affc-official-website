# الاتحادية الجزائرية للكلانات

الموقع الرسمي للاتحادية الجزائرية للكلانات (AFFC).

## عن المشروع
منصة رقمية رسمية لتنظيم وإدارة مسابقات الكلانات الجزائرية في لعبة eFootball.

## أهداف الموقع
- عرض الكلانات المعتمدة.
- تنظيم البطولات والمسابقات.
- نشر جدول المباريات والنتائج.
- عرض الترتيب والإحصائيات.
- إدارة اللاعبين والعقوبات.
- استقبال طلبات انضمام الكلانات.
- توفير لوحة تحكم للإدارة ومسؤولي الكلانات.

## التقنيات
- React
- TypeScript
- Vite
- Supabase

## اللغة والتصميم
- اللغة العربية.
- واجهة RTL.
- تصميم متجاوب مع الهواتف والحواسيب.
